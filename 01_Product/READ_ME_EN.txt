FASTEST OFFLINE START
Extract this folder. Open CyberLearn.html in a current desktop browser. Select English or Қазақша in the language selector (Russian is also available). Choose Teaching, Admissions or Finance and enter a fictional participant code of 2–20 Latin letters, digits or hyphens, e.g. STAFF-01. No learner account, password, internet or external library is needed. Do not use real names, IDs or work messages.

WINDOWS INSTALL (optional)
Run Install_Windows.cmd from this extracted folder on an authorised machine. It copies the application to %LOCALAPPDATA%\CyberLearnCampusQuest and opens the HTML. The portable HTML also works without the installer. Removing that folder removes installed files, not previously exported reports or browser records. Use the reviewer controls or delete the authorised browser profile separately. Keep the file path/profile stable when resuming a shift or returning after seven days; storage availability depends on the browser and its policy.

CORE JOURNEY
Select desk and code → four opening items → short guide → four guided role-specific items → four different independent items → results → handoff. Each email needs a classification and a next action. To demonstrate a safe boundary, enter ! as the code, then correct it. Choose a recognised training route, not a real email link. No message is sent and no genuine credentials are requested.

REVIEWER HANDOFF
Offline: export an attempt as JSON, share it privately with the intended reviewer (e.g. LMS), then import it in the reviewer tab. File download by itself is not confirmation of receipt. The reviewer can inspect each decision, filter attempts, export selected rows or delete selected attempts. Shared offline storage is not an authenticated private account. For rehearsal, complete a training run with a new demonstration code and export its record. Use no real staff data.
Optional single-computer classroom: Python 3.9+ standard library. Open a terminal here and run: python classroom.py
The terminal prints two tokenised URLs. Use the PRIVATE reviewer URL only on this same computer. Open the learner invitation in another browser/profile. Classroom submissions create an HTML report and JSON file in Reviewer_Inbox beside the server by default. Tokens change on restart. If sharing a pilot on an authorised isolated LAN, Start_Class_Windows.cmd or python classroom.py --lan prints a learner LAN invitation. Do not publish this receiver on the public internet or expose private URLs. Its default single-device mode binds to loopback. On a network that isolates devices, use manual JSON handoff. Stop the server with Ctrl+C.
